# Release scope / 发布范围

Only allowlisted text source, aggregate results, sanitized SVG figures and synthetic demo assets are included. No inherited Git history. No raw measurements, fitted checkpoints, private caches, source data dictionaries, coordinates or per-turbine acquisition lists are licensed or bundled.

采用新仓库、文件白名单及脱敏检查。图形中的汇总结果来自冻结研究，合成界面仅演示流程。历史原型包和完整图集包包含私有内容，不能上传。检查表、申请书及内部讲稿仅本地保存。

The empirical workflow cannot be rerun without separately authorized private inputs. The public demo and tests can run without those inputs. Names and field codes in code have been anonymized; original input mappings must be provided privately.
