# 研究方法与项目进度

原申请路线：图建模→72小时概率预测→鲁棒资源调度→端到端仿真。当前已实现可审计的时序图汇聚及联合情景路线；不把相关性写成物理传播已证实，不将申请中的全部结构写成已实现。

三值标签：任何已知小时超限即失败；全部已知且达标才成功；其余未知。阈值8/10/12仅为原始刻度。训练/校准/评价按时间分离；起报后真值只用于事后评价。

预测队列880起报、17机组；输入完整392起报。执行44起报，其中完整天气15起报仅作辅助，不能代替全体。59,840条单机预测对应16,269个物理目标，重复和种子不增加独立天气样本。

H1：同24小时信息图/均值/自身历史对照，加28日气候和112日类比强基线。H2：保持边际多重集，改变时间/空间联合排列，评价单机和共同连续6小时事件。H3：固定/滚动校准×即时/72小时规划×固定/自身预订；两校准法都每6小时接收当前预报。Residual28是另一个校准分支，未进入该执行交叉。

共享机组小时约束收紧费用识别界；费用与成功数分别优化，不把端点拼为共同可实现矩形。罚损敏感性保持动作固定，并非各权重重新规划。情景归并/支配及有界式仅在保存工程实例核验，不宣称任意输入稳定性。

进度：数据和标签治理、模型与对照、联合与缺测实验、执行与信息价值、原型和论文图集均已有成果。下一步按“字段/时间验收→保留预测动作重评分→冻结协议→独立年度与真实海况验证”推进。当前暂停扩张同年模型搜索。
