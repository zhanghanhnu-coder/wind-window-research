# 贡献与公开材料维护

欢迎改进双语文档、图例、可访问性、合成演示和算法审查。新实验应明确区分合成验证与真实数据结果。

## 提交前

- 文档注明比较方向、评价对象、指标和范围类型；中英文同步。
- 代码变更说明触发条件、预期行为及验证方式。
- 演示修改运行[公开检查](reproducibility.zh.md)，并实际检查页面。
- 研究算法修改说明适用分支和输入契约；不能仅凭合成单元测试宣布实证重现。
- 图表使用清楚的单位、图例和分母；识别范围不标为置信区间。

## 不要提交

原始或清洗后的时序、字段字典、真实场站名/坐标、模型权重、私有缓存、逐起报输出、动作账本、补录明细、个人资料、凭据或带有这些信息的截图。即使改名为xx风电场，也不自动允许公开数据。请使用虚构的小样例描述问题。

## 问题报告建议

说明仓库版本、Python/浏览器版本、运行命令、实际与预期行为及去除私有信息后的错误信息。不要直接粘贴整个研究日志或本机目录。数据请求应通过授权私有渠道，不在公开Issue附上。

项目代码与文档按[MIT许可证](../LICENSE)发布；第三方组件保留各自许可。数据不在许可范围。学术引用时记录仓库URL、提交哈希及访问日期；目前不提供未经证实的论文DOI或发表信息。
